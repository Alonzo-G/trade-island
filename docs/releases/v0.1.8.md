# v0.1.8 — 悬停展开延迟可调

## 更新内容

- **悬停展开延迟可设置**：设置 > 展开与收起 > 展开方式选「鼠标悬停」时，新增"悬停后展开延迟"（0–5 秒，步进 0.5 秒），默认 **0.5 秒**——鼠标停在小岛上半秒才展开，扫过不再误触
- 填 0 恢复上游的立即展开行为
- 从 v0.1.7 检查更新即可升级

## What's New

- **Adjustable hover delay**: Settings > Opening & closing > Hover shows a "hover expand delay" row (0–5 s, 0.5 s steps), defaulting to **0.5 s** — brushing past the island no longer throws the panel open; 0 restores instant open
