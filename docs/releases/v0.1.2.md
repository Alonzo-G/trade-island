# v0.1.2 — 拖动与侧面停靠

## 更新内容

- **展开态拖动**：展开小岛后，按住顶栏空白处即可拖动整个岛（按钮、输入框不受影响）
- **侧面停靠**：把岛拖到屏幕左缘或右缘 16px 内会自动吸附贴边，拖离即解除；三个边同时靠近时吸附最近的
- **应用内更新可用**：本版本起内置更新签名公钥，以后可从 v0.1.2 直接自动升级（v0.1.0 因发布时未配密钥不具备此能力，请手动安装本版）
- **回归页与测试同步**侧边吸附改动

## What's New

- **Expanded drag**: press the expanded island's header to drag the whole island (buttons and inputs unaffected)
- **Side docking**: drop the island within 16px of the screen's left or right edge to snap it there; drag away to release
- **In-app updates live**: builds now carry the updater public key — future versions update automatically from v0.1.2 (v0.1.0 predates the signing key; install this one manually)
