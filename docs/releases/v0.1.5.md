# v0.1.5 — 展开态拖动与快捷应用独立页

## 更新内容

- **展开态可以拖动了**：修复上游限制——之前只有收起的小胶囊能拖；现在展开岛后按住顶栏空白处即可拖动整个岛
- **快捷应用独立成页**：从外贸工具页拆出，岛上新增独立圆点（宫格图标），图标更大更好点
- **插件页清理**：移除上游遗留的内置插件（钉钉/飞书/企业微信/Cursor/Kimi 等），市场为空直到我们的外贸插件上线；开发者模式自定义索引不受影响
- 从 v0.1.4 点「检查更新」即可升级

## What's New

- **Expanded drag fixed**: upstream only let the collapsed capsule drag; now press the expanded island's header to drag the whole island
- **Quick apps gets its own page**: separated from the trade tools page, a dedicated island dot with a larger grid
- **Plugin page cleaned**: upstream built-in plugins (DingTalk/Feishu/WeCom/Cursor/Kimi…) removed; the market stays empty until trade plugins ship
