# v0.1.7 — 拖动与悬停深度优化

## 更新内容

- **悬停不再无限跳动**：修上游穿透循环与展开动画的竞态——鼠标悬停触发展开时，动画期间岛保持捕获鼠标，不再反复收起/展开
- **拖动全程稳定**：拖动中鼠标永不丢失（之前拖到一半岛会"脱手"收起）
- **侧边吸附修好**：之前按窗口矩形（含 200px 透明边距）判断，岛看着贴边了吸附永不触发；现在按岛的可见矩形判断与落位
- **快捷方式拖入直达**：.lnk/.exe/.url 拖到岛上任意位置都进快捷应用，不再被文件中转截走
- **新增一键居中**：设置 > 位置 > 一键居中，把岛放到当前屏幕工作区正中（水平垂直居中）
- 从 v0.1.6 检查更新即可升级

## What's New

- **No more hover jitter**: the passthrough loop raced the expand animation; the island now holds the mouse through it
- **Stable dragging**: the mouse never escapes mid-drag
- **Side snapping works**: judged by the island's visible rectangle, not the stage window's transparent margins
- **Shortcuts drop straight in**: .lnk/.exe/.url go to quick apps from any page
- **New one-click center**: Settings > Position > Center puts the island in the work area's middle
