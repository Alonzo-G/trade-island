# v0.1.6 — Alma 会话适配

## 更新内容

- **Alma 接入 Agent 页**：Alma 跑任务图（plan）时，岛上状态灯变蓝、Agent 页出现"Alma"会话，显示"3/7 任务完成"进度；全部完成变绿，30 分钟无更新转黄
- **工作区识别**：岛的待办保存目录即 Alma 工作区——目录里有 `.alma/plan.json` 就会显示
- 从 v0.1.5 点「检查更新」即可升级

## What's New

- **Alma on the Agent page**: when Alma runs a task plan, the island's status light goes blue and an "Alma" session shows progress ("3/7 tasks done"); all done turns green, 30 min of silence turns stale
- **Workspace detection**: the island's todo save directory is Alma's workspace — a `.alma/plan.json` there is all it takes
