# v0.1.0 — 外贸工具岛首个版本

基于 fly-island 深度改造的外贸工作台岛。

## 外贸功能

- **客户消息雷达**：WhatsApp / Telegram / QQ 桌面版通知直达小岛
- **外贸工具页**：客户时区（工作中/周末标注）、美元汇率环、快速报价器（FOB/CIF）、AI 写作助手（开发信/询盘回复/跟进/致谢/投诉五个场景）
- **跟进 CRM**：待办支持 @客户 @国家 #天数 标签，完成后自动排下一次跟进
- **商务翻译**：直译 / 商务正式 / 商务友好三档语气
- **插件市场**：开放插件体系，索引自主可换

## 基础

- 岛壳、动效、贴边收起、玻璃质感继承自 fly-island（GPL-3.0）
- 支持应用内自动更新（签名校验）
