# v0.1.4 — 快捷应用

## 更新内容

- **快捷应用栏目**：外贸工具页新增第四段——把常用应用的快捷方式（.lnk / .exe / .url）直接拖进小岛，随时一键启动
- **真实图标**：每个快捷方式显示从应用本身提取的原生图标
- **拖动排序**：按住图标互相交换位置，顺序自动保存；悬停可删除
- **丢失检测**：目标应用被卸载或移动后自动变灰提示
- 从 v0.1.3 点「检查更新」即可升级

## What's New

- **Quick apps**: the trade tools page gains a fourth section — drop .lnk / .exe / .url shortcuts and start them with one click
- **Real icons**: each tile shows the app's native extracted icon
- **Drag to reorder**: swap tiles to arrange; hover to remove; order persists
- **Missing detection**: shortcuts whose target was uninstalled gray out
